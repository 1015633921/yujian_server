# 上线准备审计摘要

审计日期：2026-07-12

当前结论：**NO-GO**。

已完成的上线加固范围：

- R01：用户私有接口缺少可靠服务端认证，信任客户端 `user_id`。
- R02：未公开的 DIY 方案可以通过普通方案 ID 从共享接口读取。
- R05：服务端头像远程下载允许用户控制 URL，存在 SSRF 风险。
- R03：订单价格信任客户端、SKU 校验 fail open。
- R04：订单无幂等、库存无预占、并发超卖。

实施复审补充发现并纳入 R01：缺少微信配置时的 dev 身份回退，以及未经显式信任就接受 CloudBase 身份头，都可能绕过真实微信身份校验。两条路径现已改为显式开关且默认关闭。

P0-B 已将创建订单改为服务端 SKU 定价、严格 SKU 校验、用户级幂等请求、事务内库存预占，并提供幂等确认、释放和过期处理入口。`COMMERCE_CHECKOUT_ENABLED` 仍默认关闭；真实支付、退款和物流任务不在本阶段范围。即使 P0-A/P0-B 自动化验收通过，项目整体仍保持 NO-GO，直到隔离 MySQL 并发门禁及剩余 P0/P1 发布门禁全部关闭。

P1-A 增加数据库级支付/退款事件去重、严格通知校验、事务化支付状态与库存确认，以及前端服务端确认式支付结果。`COMMERCE_CHECKOUT_ENABLED` 和 `WECHAT_PAYMENT_ENABLED` 均默认关闭。隔离 MySQL 迁移与并发事件门禁未通过前，P1-A 不得标记完成，项目整体继续 **NO-GO**。

P1-B 已增加不可变报告快照、用户级报告版本、生成幂等、报告/依据/海报/DIY 推荐版本绑定、脱敏海报 DTO，以及明确的地点校准状态。`REPORT_VERSIONING_V2_ENABLED` 默认关闭。仓库只有 11 个已有可信城市坐标，远少于前端地点范围；共享 MySQL 迁移与并发门禁也尚未执行，因此 P1-B 当前为 **BLOCKED**，不得宣称全国地点校准或开启报告 V2。

P1-C 已将物流同步移出 Uvicorn worker，增加独立进程、数据库租约、有限重试、任务运行记录、request ID、JSON 脱敏日志、统一安全异常、liveness/readiness 和轻量业务指标。物流与指标端点默认关闭。P1-C 的 SQLite/本地自动化通过，但生产 MySQL 租约门禁、Docker Compose 配置验证和测试环境运行验收尚未完成，因此当前仍为 **BLOCKED**，项目整体继续 **NO-GO**。
