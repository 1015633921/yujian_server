## 原问题

推荐器同时使用两套语义：

- 测算画像使用中文五行：`金/木/水/火/土`。
- 材料知识使用稳定键：`metal/wood/water/fire/earth`。
- 用户核心愿望使用完整中文文案。
- 材料愿景使用 `wealth/career/...` 标签。

材料知识进入推荐器时未做边界转换，导致数据库材料的元素和愿景匹配分失效。财富愿望场景中，黄水晶只得到基础池分，绿幽灵仅凭“适合作主石”规则反超。

五行归一化后还暴露出原有库存回退问题：主石覆盖多个元素时，严格排除可能没有可售辅石；旧逻辑会选择库存不存在但理论元素更合适的材料。

## 整改内容

1. 材料知识进入推荐目录时统一转换为中文五行。
2. `crystal_elements()` 对静态目录、数据库知识和测试目录执行同一归一化。
3. 增加四类核心愿望到标准愿景标签的明确映射。
4. 愿景评分改为标签集合相交，不再直接比较中文整句和英文键。
5. 动态材料愿景标签可以参与对应中文核心愿望的主石池。
6. 最终元素画像得分按归一化后的主元素读取。
7. 辅石回退顺序调整为：
   - 可售且所有元素不重叠；
   - 可售、主元素不重叠，允许次元素重叠；
   - 其他可售且角色合法的材料；
   - 不再为追求元素完全匹配优先选择无库存材料。
8. 点睛材料同样优先保持可售；没有独立可售点睛材料时复用已验证的可售辅石，而不是选择无库存 SKU。
