## 8. 后续恢复规则

停用 SKU 修复图片、图库或物理规格后，可以逐个重新启用，但每个 SKU 必须满足：

1. 主图和缩略图返回 200。
2. 图库至少有一张可访问图片，且不依赖主图作为随机图。
3. 非圆配饰已填写真实 `body_width_mm` 和 `body_height_mm`。
4. 后台启用后，正式材料接口能返回该规格。
5. 在工作台实际加入一次，确认图片、比例、占位和价格正确。
