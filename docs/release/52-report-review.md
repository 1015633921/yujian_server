## 数据一致性判断

- V2 开启后，报告页、依据页、海报和 DIY 推荐可以绑定同一报告版本。
- 用户资料、MBTI 或算法后续变化不会改写既有快照。
- 旧报告的稳定性由快照保证，而不是重新计算保证。
- 未知地点明确降级，不生成伪造校准值。
