# 第三方调用稳定性策略

| 服务 | 当前超时 | 自动重试 | 幂等与失败处理 |
|---|---:|---|---|
| 微信登录/手机号 | 8 秒 | 不自动重试 | code 可能一次性消费；失败分类为 `wechat_auth` |
| 微信支付/退款 API | 12 秒 | 不在 HTTP 请求内自动重试 | 依赖订单/退款业务幂等；只返回安全 HTTP 状态错误 |
| 微信支付/退款回调 | 被动请求 | 微信重投，由事件唯一键去重 | 失败响应不返回内部异常原文 |
| 微信交易管理 | 12 秒 | 仅按有限 order key 候选尝试 | 发货上传依赖微信侧订单键与本地状态，不无限重试 |
| 快递100 | 10 秒 | 独立 worker 仅重试失败订单，最多 3 次 | 查询只读；成功覆盖最近轨迹；失败保留旧轨迹 |
| 远程头像 | 每个固定 IP 6 秒 | 仅遍历已解析且安全的有限 IP | SSRF 校验、大小限制、禁止跳转；默认关闭 |
| 腾讯 COS | 默认 15 秒，范围 3-60 秒 | 使用 SDK 有界行为，不在业务层循环 | 上传失败分类为 `tencent_cos`，不记录对象内容或密钥 |
| CDN | 无主动调用 | 无 | 仅生成经过规则约束的资源 URL |

所有主动 HTTP 调用携带当前 `X-Request-ID`，但不携带用户隐私。异常日志只包含服务名、错误类型和安全状态码。不得记录带 access token 的 URL、Authorization、响应正文、OpenID、手机号或地址。

重试必须建立在幂等语义上。登录 code、支付预下单和退款申请不做通用网络自动重试；由上层幂等键、状态查询或人工补偿决定后续动作。任何新增外部服务必须在接入评审中明确 connect/read/write timeout、最大尝试次数、可重试错误、幂等键、降级行为和指标名。
