材料目录 · 操作总览

先目录，后 SKU

运营添加材料时必须按层级完成，不能把材质、款式和规格写在同一级。

  1. 确认材料类型
  2. 创建材料分类
  3. 创建品种 / 款式
  4. 完善品种资料
  5. 创建具体 SKU
类型、分类、品种是可复用目录；尺寸、价格、库存属于 SKU。

STEP 1 · 材料类型

创建材料类型

一级目录用于隔离珠子和配饰。现有“珠子、配饰”可以直接复用，不要重复创建。

  1. 进入“材料类型”
  2. 点击“新增类型”
  3. 填写名称与稳定编码
  4. 启用后保存
类型编码创建后不可修改。中文名称可以调整。

STEP 2 · 材料分类

创建材料分类

分类描述“这是什么材料大类”，不描述颜色、尺寸或库存。

  1. 进入“材料分类”
  2. 点击“新增分类”
  3. 先选材料类型
  4. 填写分类名称并保存
示例：幽灵随形属于“配饰”；幽灵水晶属于“珠子”。

STEP 3 · 品种 / 款式

级联选择品种归属

先选择材料类型，分类下拉只会显示该类型下的分类，避免把珠子品种放进配饰目录。

  1. 选择“配饰”
  2. 分类选择“幽灵随形”
  3. 填写“绿幽灵随形”
  4. 保存目录
切换材料类型时，原来不匹配的分类会自动清空。

STEP 4 · 完善品种资料

完善可复用资料

品种资料控制工作台外观和推荐匹配。同一品种的多个 SKU 共用这些信息。

  1. 在品种列表点击“完善资料”
  2. 上传规范材料图片
  3. 选择工作台形制
  4. 填写推荐与养护资料
图片走统一素材管线并上传 COS；不要把临时抠图直接上传。

STEP 5 · 创建 SKU

录入可售规格

SKU 才填写实际尺寸、价格和库存。随形材料一颗一库存时，每颗建立独立 SKU。

  1. 级联选择目录路径
  2. 填写展示名与价格
  3. 录入库存
  4. 实测工作台规格
  5. 检查后启用
随形、双尖、花托、吊坠不能只填“珠径”，必须填写外观宽高和穿线占位。
