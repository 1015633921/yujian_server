# 宇涧人工搭配设计规范（V1）

适用范围：人工搭配服务。设计师在线下完成真实选材和成串，后台只上传已完成方案图片与简短说明；不使用设计师工作台，也不接收 AI Design Brief。

## 1. 先读用户需求

设计师只参考用户在申请中明确填写的：手围、珠径、预算、风格、色彩偏好、配饰偏好、佩戴场景与备注。测算报告用于用户自我理解，不把出生信息或原始测算输入展示给设计师。

若偏好冲突，以用户明确备注优先；没有明确偏好时，采用“清透自然、日常佩戴、低饱和”的安全默认方向。

## 2. V1 风格语言

| 风格 | 色彩与材质 | 结构 | 避免 |
| --- | --- | --- | --- |
| 清透自然 | 蓝白、雾绿、透明系 | 1 主材 + 1–2 辅材，留白 | 大面积深色、过多金属 |
| 高级极简 | 单色/邻近色、净体材质 | 1–2 材质、对称或弱对称 | 强撞色、复杂隔片 |
| 温柔治愈 | 柔粉、月光白、浅紫 | 圆润节奏、低对比 | 高饱和红黑、过密点缀 |
| 东方禅意 | 米白、茶色、墨绿 | 稳定重心、少量金属 | 过多闪亮配件、堆叠纹理 |

## 3. 成串底线

- 常规款最多 3 种珠材；异形配饰最多 2 处，并保持左右视觉平衡。
- 金属配饰只在“适合风格且能够提升层次”时使用，不能为凑元素强行加入。
- 同一串只保留一个视觉主角；辅助材负责过渡，不与主材抢焦点。
- 珠径、手围和预算必须与申请一致；若需要改变，先在图片说明中写明原因。
- 真实材料天然纹理允许存在，但不能用失焦、严重色偏或遮挡来掩盖问题。

## 4. 图片交付标准

- 每次提交至少 1 张完整成串图；建议另附 1 张局部细节图。
- 使用自然或中性光，背景干净，成串主体占画面 70% 以上。
- 不使用过度滤镜、合成高光或会改变水晶真实颜色的调色。
- 标题写“风格 + 场景”，例如“清透日常通勤款”；说明只写色彩、层次与佩戴感，不写功效承诺。

## 5. 服务状态

`已提交 → 设计中 → 方案待确认 → 已确认 / 待调整`。

用户确认的只是设计方向。由于 V1 只上传方案图片而没有录入每颗实物 SKU，库存核验和实际制作在确认后由客服按真实材料再次确认；提交图片阶段不冻结库存。
