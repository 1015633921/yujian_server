# 手串有效内圈物理模型

## 为什么不能把珠径直接相加

`珠径总和`近似表示弹力绳穿过珠孔中心形成的闭合折线长度，不是手腕真正能占用的内圈周长。圆珠围成一圈后，珠体半径会向内侵占空间；珠径越大，这个差异越明显。

工作台因此区分：

- `珠心路径`：弹力绳穿过各珠孔中心形成的闭合路径。
- `有效内圈`：珠体向内占位后，近似可容纳手腕的周长。
- `舒适松量`：在裸手围之外预留的佩戴余量，当前为 8mm。

## 等径圆珠的解析公式

假设：

1. 所有珠子为直径 `d` 的圆珠；
2. 珠孔经过球心；
3. 相邻珠子彼此接触；
4. 珠心位于同一个半径为 `R` 的圆上；
5. 弹力绳暂不考虑拉伸。

`N` 颗珠子的相邻珠心夹角为 `2π/N`。相邻珠心距离既等于珠径 `d`，也是珠心圆的一条弦：

```text
d = 2R × sin(π/N)
R = d / (2 × sin(π/N))
```

珠体向内占用半径 `d/2`，所以有效内圈为：

```text
L_inner = 2π × (R - d/2)
        = πd × (1 / sin(π/N) - 1)
```

这来自圆的弦长关系 `chord = 2R sin(θ/2)` 和圆周长 `2πR`。弦长与圆周关系可参见 [Wolfram MathWorld: Circle Line Picking](https://mathworld.wolfram.com/CircleLinePicking.html)，弧长关系可参见 [OpenStax: Relating Arc Lengths to Radius](https://openstax.org/books/algebra-and-trigonometry-2e/pages/7-1-angles)。

示例：

```text
20 颗 × 8mm：
珠径总和 = 160.0mm
有效内圈 ≈ 135.5mm

22 颗 × 8mm：
珠径总和 = 176.0mm
有效内圈 ≈ 151.5mm

24 颗 × 8mm：
珠径总和 = 192.0mm
有效内圈 ≈ 167.4mm
```

这也说明旧公式“珠径总和减 1 颗平均珠径”会严重高估可戴内圈。等径珠数量较多时，几何损耗趋近 `πd`，不是 `1d`。

## 混合珠径模型

对于按顺序排列的不同珠径 `d_i`，令半径 `r_i = d_i/2`。相邻两颗珠子接触时，珠心弦长为：

```text
c_i = r_i + r_(i+1)
```

给定珠心圆半径 `R`，这对珠子占据的圆心角为：

```text
θ_i = 2 × asin(c_i / (2R))
```

通过二分法求解闭合条件：

```text
Σ θ_i = 2π
```

第 `i` 颗珠子承担的角域取相邻两段圆心角的平均：

```text
φ_i = (θ_(i-1) + θ_i) / 2
```

最终有效内圈：

```text
L_inner = Σ (R - r_i) × φ_i
```

这个算法会保留珠子的真实排列顺序，因此混合珠径、主珠和配珠的组合可以得到不同内圈结果。

## 推荐颗数

```text
目标有效内圈 = 裸手围 + 8mm 舒适松量
```

系统不再用 `目标长度 / 平均珠径` 直接取整，而是在允许的颗数范围内逐一计算物理内圈，选择最接近目标的颗数；误差相同则优先选择不偏短的方案。

当前范围：

- 推荐方案：12–40 颗；
- DIY 工作台：最多 40 颗；
- 推荐有效内圈允许误差：±5mm。

## 异形珠与配饰规格

形制与安装方式在运营后台的“材料分类 / 品种”中维护，实物尺寸在具体 SKU 中维护。不要根据素材图片的透明画布或文件名估算尺寸。

品种级字段：

- `bead_shape`：圆珠、桶珠、方糖、随形、双尖、弯管、连接件、扣件或吊坠等真实形制；
- `placement_mode`：有贯穿孔并串在线上使用 `threaded`，通过吊环向外下垂使用 `hanging`，包在主珠单侧使用 `attached_side`；
- `image_string_axis_deg`：素材图片中穿线方向为竖向填 `90`，横向填 `0`，用于让实物切线方向与手串一致。

SKU 级字段均按实物卡尺测量：

- `size_mm`：配饰或异形珠的外观最大尺寸，仅用于商品规格和显示上限；
- `string_axis_width_mm`：穿线后实际占用绳长。随形珠测两侧孔口沿穿线方向的距离，隔片测厚度，吊坠测吊环在绳上的占位；
- `body_width_mm` / `body_height_mm`：与原始素材方向一致的外观宽、高，决定工作台显示比例和碰撞范围。
- `compatible_bead_size_mm`：包珠隔片适配的主珠珠径；`compatible_size_tolerance_mm` 为允许误差，未填误差时前端按 ±0.6mm 判断。

包珠隔片不作为独立串珠占用圆环位置，而是挂在主珠 placement 的 `bead_caps.left` 或 `bead_caps.right` 槽位。单颗主珠可以只包一侧或两侧；相邻主珠的内侧槽位可以各装一个，从而形成两个隔片背靠背。每个已占用槽位都展开为一条独立订单 SKU，单独计价和扣库存，但不重复计入主珠数量、内圈长度或五行占比。

同一品种的不同尺寸必须分别录入 SKU 实测值。非圆形材料缺少上述三个 SKU 级尺寸时，工作台会显示“规格待补”并阻止加入，避免用默认圆珠尺寸生成失真的方案。

## 模型边界

- 本模型适用于圆珠、珠孔近似过球心、相邻珠子接触的闭合弹力手串。
- 随形珠、桶珠、条形吊坠应使用沿穿线方向的实际占位宽度 `string_axis_width_mm`，不能套用外接直径。
- 弹力绳预拉伸、打结余量、珠孔偏心、珠间隔片和手腕椭圆度会带来实物误差。
- 8mm 舒适松量是产品参数，不是几何常数；应继续用 6mm、8mm、10mm、12mm 实物样品校准。

## 实物校准

每条样品记录：

1. 珠子顺序与每颗沿穿线方向占位宽度；
2. 打结前后弹力绳长度；
3. 圆规实测内圈或标准手围棒读数；
4. 对应裸手围下的主观松紧等级。

几何模型负责给出无拉伸基线，实测数据只校准舒适松量、弹力绳伸长和异形珠占位，不再使用单一“损耗系数”掩盖所有误差。
